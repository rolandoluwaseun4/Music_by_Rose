# Music_by_Rose# 

A simple and responsive music website built to showcase songs, artists, and vibes.  
Designed with clean UI, smooth layout, and a focus on user experience.

## 🚀 Features
- 🎶 Music-focused layout
- 📱 Fully responsive (mobile, tablet, desktop)
- 🎨 Clean and modern design
- ⚡ Fast loading and lightweight
- 🧭 Easy navigation

## 🛠️ Built With
- **HTML** – structure  
- **CSS** – styling and layout  
- **JavaScript** – interactivity
